Как пользоваться

1. Выбери тип кассеты или CD. 2. Загрузи фото для нужной стороны. 3. Впиши название и песни. 4. Создай PDF и распечатай его на A4.

Размеры: кассета: 65,1 + 12,7 + 25,4 мм, высота 101,6 мм. Доп. разворот: ещё 65,1 мм. CD перед: 120 × 120 мм. CD зад: 150 × 118 мм с двумя корешками по 6,25 мм. Разворот CD: 240 × 120 мм.

Шаблоны предназначены для стандартных прозрачных коробок Jewel Case и Norelco. Нестандартные футляры нужно измерять отдельно.

Важное: PDF содержит точный размер страниц. При печати с iPhone открой PDF, выбери «Поделиться» → «Печать» или передай документ на компьютер. Отключи масштабирование и проверь 50-мм линейку на первой распечатке.

На экран «Домой»: открой сайт в Safari → Поделиться → На экран «Домой». Работает без аккаунта; проекты хранятся на устройстве. Для подстраховки используй кнопку «Сохранить проект в файл».
