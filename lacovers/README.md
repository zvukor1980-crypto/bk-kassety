# ЛакОбложки 5.0 — пошаговый мастер для iPhone

Постоянная ссылка: https://zvukor1980-crypto.github.io/bk-kassety/lacovers/

## Работа в один вопрос за раз
1. Начать с нуля или продолжить сохранённый проект.
2. Выбрать аудиокассету или CD.
3. Выбрать точный тип вкладыша: кассета J, кассета XL, CD передняя, CD задняя, комплект CD или двухпанельный буклет.
4. Для каждой предусмотренной стороны решить, нужно ли фото, и при необходимости выбрать его из iPhone.
5. Выбрать способ размещения: целиком с мягким фоном, целиком с ровным фоном, или на всю область с **явно разрешённой** обрезкой.
6. Выбрать, нужны ли надписи. По умолчанию **нет**. Любые названия, треки и подписи вводятся или выбираются пользователем; программа ничего не подставляет автоматически.
7. Выбрать оригинальное фото, нейтральный студийный фон или декоративный стиль.
8. Проверить макет A4 и отправить на печать (PDF, цвет/оттенки серого, копии, опционально двусторонняя кассета).

## Фотографии
- Исходное соотношение сторон сохраняется. Портретное фото остаётся портретным, горизонтальное — горизонтальным.
- Режим по умолчанию: `contain-blur`, изображение **целиком** без обрезки, пустое пространство заполнено мягким фоном.
- Обрезка возможна только после явного выбора `cover` или увеличения пользователем.
- Размещение и поворот отдельно для каждой стороны; каждый проект хранит собственные изображения.

## Сохранность и совместимость
- IndexedDB `lacovers-projects-v1` **не изменена**; ранее созданные проекты сохраняют данные и старое поведение без незапрошенной миграции.
- Исходный редактор v4 доступен через «Ручной редактор и дополнительные инструменты».
- Новый проект создаётся без текста и без изображений. Никакие надписи автоматически не накладываются на фотографию.
- Уже сохранённые проекты можно экспортировать с изображениями из ручного редактора.

## Печать
Аудиокассета 103,2 × 101,6 мм; кассета XL 168,3 × 101,6 мм; CD перед 120 × 120 мм; CD зад 150 × 118 мм; CD буклет 240 × 120 мм. PDF формируется на A4 с заданными размерами. Физически точный результат требует печати в масштабе 100%; один раз проверьте квадрат 100 × 100 мм на пробном листе.

## Установка
Открыть страницу в Safari → Поделиться → На экран «Домой». Переустанавливать старый ярлык для перехода с v4 на v5 не требуется.
