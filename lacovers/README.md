# ЛакОбложки · версия 2.0

Веб-приложение (PWA) для iPhone через Safari → Поделиться → На экран Домой.

Адрес: https://zvukor1980-crypto.github.io/bk-kassety/lacovers/

## Возможности
- 6 стандартных раскладок кассет / CD
- 15 стилевых тем, шрифты, цвета, фото для разных сторон
- Редактирование горизонтального и вертикального сдвига фотографии и масштаба
- Вкладыши кассет: раздельная наружная/внутренняя сторона, опциональная двусторонняя печать с чередованием страниц
- Комплекты CD с обложкой, тыльным вкладышем и корешками
- Несколько копий на листе A4; цвет и градации серого; 200/300 DPI
- PDF размером A4 точно в мм; метки обрезки, сгибов, линейка 50 мм
- Отдельный пробный PDF с квадратом 100 × 100 мм для проверки масштаба
- Проекты с фотографиями хранятся локально в IndexedDB; экспорт и импорт резервной копии JSON
- Офлайн-режим после первого открытия (service worker)

Печать 100% / Actual size. Для двустороннего J-вкладыша на A4 в портретной ориентации выбирайте переворот по длинной стороне и сначала сделайте пробную печать. Реальные принтеры могут добавлять поля, поэтому точность нужно проверить бумажной линейкой.

Размеры подходят для стандартных футляров: J-card 103.2×101.6 мм и 168.3×101.6 мм; CD front 120×120 мм; CD back 150×118 мм; CD booklet 240×120 мм. Нестандартные футляры измеряйте отдельно.
