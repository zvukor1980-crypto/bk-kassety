# ЛакОбложки v10 — расширенный мастер печати для iPhone

Постоянный адрес: https://zvukor1980-crypto.github.io/bk-kassety/lacovers/

## Улучшения
- Пять наглядных сенсорных карточек для печати полного вкладыша и его частей, вместо неудобного выпадающего списка.
- 1, 2, 4, 6, 8, 12, 18 или 24 копии — приложение автоматически распределяет по A4.
- По физическим размерам на один A4 помещаются до 18 корешков кассеты по 12,7 × 101,6 мм, с 8-мм промежутками для разрезания.
- Новая пробная выкройка A4 без фото, цветных заливок и надписей. Геометрия в точных миллиметрах, с линиями сгибов и контрольным отрезком 50 мм. Можно печатать и примерять к настоящему футляру перед дорогой цветной печатью.

Полный вкладыш, CD и кассеты в режиме отдельной детали печатаются без искажения пропорций фотографий. Старые проекты остаются в прежнем IndexedDB. Печать — фактический размер 100%, без Fit-to-page.
