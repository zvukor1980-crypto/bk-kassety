# ЛакОбложки · версия 6.0.0 — исправленный вкладыш кассеты

Программа: https://zvukor1980-crypto.github.io/bk-kassety/lacovers/

## Главное исправление
Раньше отдельной фотографии узкого корешка не существовало. Картинка, которую пользователь считал корешком, попадала в широкую заднюю панель.

Теперь шаблон кассеты печатается как три **смежные** части (слева направо):
- задний клапан 25,4 × 101,6 мм;
- узкий корешок **12,7 × 101,6 мм**;
- передняя обложка **65,1 × 101,6 мм**.

Общая ширина J-карты 103,2 мм, высота 101,6 мм. Полосы соединены без зазора, с отметками сгибов. Дополнительный XL-разворот: 65,1 мм. PDF A4 в физических миллиметрах, контрольная линейка 50 мм. При печати выбирайте масштаб 100% / Actual size; устройства с AirPrint могут не показывать этот параметр — обязательно измерьте линейку на тестовом листе.

## Изменения
- В мастере добавлен специальный шаг **«Фотография корешка»**; фотография переда и узкий корешок редактируются отдельно.
- Программа распознаёт фотографии с типично очень узким вертикальным форматом и автоматически переносит ошибочно загруженный на задний клапан корешок в нужную панель (без изменения изображения).
- На экране проверки показан **крупный вид полной кассетной развёртки** вместе с реальным размещением на A4.
- Встроен готовый печатный макет группы **רעש יפה — אני פה! (2026)** — одно нажатие на первом шаге. Лицевая часть и корешок взяты из работ, предоставленных пользователем, без рисования поверх них нового текста. Задний клапан оформлен нейтральным фоном.
- Фото печатаются с сохранением пропорций и без обрезки по умолчанию. Обложка не растягивается.
- Прежние проекты в IndexedDB `lacovers-projects-v1` остаются доступны; данные сохраняются в браузере iPhone. Рекомендуется экспорт коллекции в резервную копию.
- Приложение поддерживает офлайн-режим после первой полной загрузки и добавление на экран «Домой» через Safari.

## Что проверить
1. На первом экране нажмите **«Готовая кассета: רעש יפה — אני פה!»**.
2. Посмотрите крупный макет: задний клапан, узкий корешок с вертикальной надписью и лицевая обложка.
3. Нажмите «Далее» → «Создать PDF».
4. Для собственной кассеты выберите «Создать с нуля», а на шаге «Корешок» загрузите отдельную узкую картинку.
