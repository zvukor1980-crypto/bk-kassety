# ЛакОбложки v9.0 — iPhone PWA

Сайт: https://zvukor1980-crypto.github.io/bk-kassety/lacovers/

Обновление v9: автоматическое компактное размещение отдельных деталей кассет на A4 без изменения размеров в миллиметрах. 6 корешков 12,7×101,6 мм теперь помещаются на одном листе; 4 лицевые стороны 65,1×101,6 мм — на одном листе. Для широких клапанов программа раскладывает детали в несколько рядов. Между ними 8 мм для меток обрезки.

На финальном шаге показаны количество листов и фактическая раскладка выбранных экземпляров. Изменения количества экземпляров и двусторонности тут же отображаются в предпросмотре.

Без изменений: 6 форматов кассет/CD, точный A4 PDF, классический и пошаговый редактор, автоматическое сохранение проектов в IndexedDB, встроенный альбом группы רעש יפה, настройка фотографий без деформаций, выбор печати отдельных частей кассеты и проверка разрешения фотографий.

Настоящий размер на бумаге зависит от опций принтера — выбирайте 100%, без подгонки, и проверяйте линейку 50 мм.
