# ЛакОбложки 8.0 · Студия кассет и CD для iPhone

Постоянный адрес: https://zvukor1980-crypto.github.io/bk-kassety/lacovers/

Приложение PWA, установка через Safari → «Поделиться» → «На экран Домой».

## Новое в 8.0

- На последнем шаге мастер **автоматически проверяет фотографии**, которые действительно попадут на выбранную печатную деталь. Разрешение сравнивается с физическими миллиметрами и вычисляется приблизительная детализация в DPI.
- Отдельно предупреждает об изображениях с низкой плотностью пикселей, отсутствующей фотографии и явно включённой обрезке; исправление открывает нужный шаг загрузки изображения.
- Если выбран корешок, проверяется только корешок. Если весь вкладыш, проверяются все панели. Отсутствие заднего клапана, который намеренно оформляется нейтральным фоном, не считается ошибкой.
- **Увеличенное изображение выбранной детали** непосредственно над предпросмотром листа A4. Для узкого корешка холст пропорциональный, без растягивания изображения.
- Вся система остаётся необязательной подсказкой. Пользователь может печатать пустые шаблоны или использовать фотографии меньшего качества без блокировки.

## Печать

Физические размеры стандартного J-вкладыша: задний клапан 25,4 × 101,6 мм; корешок 12,7 × 101,6 мм; лицевая обложка 65,1 × 101,6 мм. Общий размер 103,2 × 101,6 мм. Кассетный XL-вкладыш 168,3 × 101,6 мм. CD front 120 × 120 мм; rear 150 × 118 мм; booklet 240 × 120 мм. PDF генерируется как страница A4 точно по геометрии PDF, с исходными макетами в миллиметрах. Точность на бумаге зависит от настроек принтера: масштаб 100% / Actual size, проверка линейки 50 мм.

## Хранение

Схема IndexedDB `lacovers-projects-v1` и форма проекта не изменялись. Прежние проекты и фотографии сохраняются. Обязательно сохраняйте резервную копию всей коллекции в файлы iPhone: браузерная база данных не является заменой резервному копированию.

## Проверки

- Мобильная ширина 390 px; скрипты без исключений и без горизонтального переполнения.
- Подсказка DPI для обоих фото группы רעש יפה, а также для изображения низкого разрешения 50×150 пикселей.
- Автоматический переход из предупреждения к соответствующей фотографии.
- Генерация PDF A4 при выборе отдельного корешка и полного вкладыша.
- Предпросмотр для всех 6 режимов: кассета, кассета XL, CD front, CD back, CD set, CD booklet.
