# ЛакОбложки — 11.0

iPhone PWA: https://zvukor1980-crypto.github.io/bk-kassety/lacovers/

Новое: два понятных шага для iPhone-печати — сначала создание PDF, затем отдельным касанием открытие системного меню «Поделиться»/«Печать». Это сохраняет требуемую iOS user activation во время вызова navigator.share.

После подготовки доступны «Печать на iPhone», «Открыть PDF» и «Сохранить PDF». Если Safari не поддерживает передачу PDF через navigator.share, файл сохраняется локально. Данные проектов остаются в прежнем IndexedDB; перед изменением любого параметра подготовленный PDF сбрасывается для предотвращения случайной печати старого варианта.

Пробная выкройка и проверка принтера перемещены под «Дополнительно». Офлайн-кэш исправлен: CSS и JS версии 11, а не 7.

Печать: A4 100% / фактический размер без подгонки. Настройка физического масштаба зависит от принтера.
