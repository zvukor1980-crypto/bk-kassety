# ЛакОбложки 4.0 — профессиональный редактор для iPhone

Постоянная ссылка: https://zvukor1980-crypto.github.io/bk-kassety/lacovers/

## Изменения интерфейса
- Четыре понятных экрана: формат, дизайн, проверка, печать.
- Строгий светлый интерфейс с графитово-синими кнопками, читаемой типографикой и достаточным контрастом.
- Крупные карточки выбора формата с размерами.
- Моментальный крупный предпросмотр отдельной стороны обложки на шаге дизайна.
- Предпросмотр готового листа A4 отдельно на шаге проверки.
- Постоянная нижняя кнопка для перехода между шагами и запуска PDF на шаге печати.
- Основные операции на виду, редкие настройки фотографии, типографики, печати, архивов — внутри раскрывающихся блоков.
- Предупреждение о масштабе принтера и отдельный пробный лист.

## Сохранено из 3.0
- Все 6 форматов и 23 цветовые темы, фото для разных сторон, стили текста, обработка снимков, песни и нумерация.
- PDF A4 точного физического формата в альбомной или книжной ориентации, метки разреза и сгибов, режим оттенков серого, калибровка 50/100 мм.
- Опциональная двусторонняя печать кассет (предварительно протестировать на обычной бумаге).
- PNG A4, экспорт и импорт резервных копий проекта и всей коллекции.
- Офлайн-кэш в scope приложения.

## Совместимость с проектами
Схема IndexedDB **не изменена**: `lacovers-projects-v1`, ObjectStore `projects`. Переименование мест хранения, миграция или удаление пользовательских фото не выполняются. Сервис-воркер обновляет только кэш приложения с префиксом `lacovers-`.

## Использование
Открыть в Safari, нажать «Поделиться» → «На экран Домой».
Печать PDF на **100% / фактический размер**, не «подгонять к листу». Реальные принтеры могут задавать поля, поэтому первый раз проверь линейкой.
